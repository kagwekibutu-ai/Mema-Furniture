# Mema Furniture

Creating Comfort. Defining Spaces.

Static marketing website for **Mema Furniture** — a furniture design, manufacturing and sales business based in Murang'a, Kenya, offering countrywide delivery.

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — hero, benefits, popular products, category mosaic, custom orders, testimonials |
| `collection.html` | Full catalogue of 36 products with live search, category filters and sorting |
| `product.html` | Product detail view (rendered from `?id=`) with related items |
| `about.html` | Story, vision & mission, core values, positioning |
| `contact.html` | WhatsApp/phone/location cards, enquiry form, workshop map, ordering process |

## Tech

- Plain HTML, CSS and vanilla JavaScript — no build step, no dependencies
- Products are data-driven from `assets/js/products.js` (prices in KES, WhatsApp ordering)
- Orders and enquiries open a pre-filled WhatsApp chat via `wa.me`
- Fraunces + Inter (Google Fonts), hand-drawn SVG scenes + optimized photography
- Scroll-reveal animations, marquee band, scroll progress bar, smart header

## Running

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
